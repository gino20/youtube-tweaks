# YouTube Tweaks

A small userscript that keeps YouTube video controls visible. Controls stay partially visible while idle and fade to full opacity when the player is hovered.

## Greasy Fork Sync

Use this raw URL to sync the script on Greasy Fork:

```txt
https://raw.githubusercontent.com/gino20/youtube-tweaks/userscript/youtube-tweaks.user.js
```

The `Build userscript` GitHub Action builds `dist/youtube-tweaks.user.js` after every push to `main`, then publishes the generated file to the `userscript` branch as `youtube-tweaks.user.js`.
